# QueueCut Landing

## Определение
QueueCut Landing — production-ready лендинг на Next.js для сервиса онлайн-резервирования в барбершопы и салоны красоты. Страница адаптирована под светлую и тёмную темы, оптимизирована под SEO и доступность, включает интерактивные формы и витрину салонов.

## Ключевые компоненты/блоки
- **Hero** — питч, CTA и форма быстрой брони.
- **Benefits** — четыре ключевых преимущества сервиса.
- **HowItWorks** — пошаговая схема из трёх шагов.
- **Salons** — витрина салонов с рейтингами и свободными слотами.
- **Testimonials** — реальные отзывы пользователей.
- **FAQ** — аккордеон с ответами на частые вопросы.
- **CTA** — повторный призыв с email-подпиской.
- **Header/Footer** — навигация, переключатель темы, контакты и соцсети.

## Применение/сценарии
- Лэндинг для предзапуска QueueCut.
- Шаблон посадочной для b2c/b2b SaaS-сервисов с записями и бронью.
- Быстрое прототипирование витрин салонов и услуг с отзывами и FAQ.

## 🔧 Конкретный пример
1. Установите зависимости и запустите dev-сервер.
2. Откройте `http://localhost:3000` и переключайте темы через хедер.
3. Заполните форму "Быстрая бронь" и отправьте — получите mock-ответ с подсветкой статуса.
4. В блоке CTA подпишитесь по email — запрос уйдёт на mock API `/api/subscribe`.

## Установка и запуск
```bash
npm i
npm run dev
```

## Архитектура
- `app/` — структура App Router с layout, страницами и серверными компонентами.
- `app/(components)/` — переиспользуемые UI-компоненты без внешних UI-китов.
- `app/(lib)/` — утилиты темы и валидаторы форм.
- `public/` — логотип и mock-скриншоты (локальные SVG).
- `docs/` — документация по стилю и тоне.
- Палитра и токены цвета задаются в `tailwind.config.ts` и `app/globals.css`.

## Темизация
- Поддерживаются светлая и тёмная темы, плюс системное значение.
- Состояние хранится в `localStorage` (`queuecut-theme`) и учитывает `prefers-color-scheme`.
- Прелоад-скрипт в `app/layout.tsx` предотвращает мигание темы.
- Контраст ≥ WCAG AA: тексты на нейтральных фонах, CTA на акценте #1f5e43.

## Доступность
- Семантические элементы (`section`, `nav`, `header`, `main`, `footer`, `button`).
- Управление клавиатурой в аккордеоне FAQ и выпадающем переключателе темы.
- ARIA-атрибуты (`aria-expanded`, `aria-controls`, `aria-label`).
- Фокус-стили Tailwind с кольцами контраста.

## SEO
- `Metadata` в `app/layout.tsx`: title, description, keywords.
- Open Graph и Twitter-теги.
- Читаемые заголовки H1–H3, структурированные секции.

## Настройка палитры и контента
- Основной акцент (`#1f5e43`) хранится в `tailwind.config.ts` и используется в классах Tailwind.
- Токены светлой/тёмной темы настроены в `app/globals.css`.
- Тексты карточек, FAQ и витрины можно править в соответствующих компонентах в `app/(components)/`.

## Mock-данные
- Вся витрина, отзывы и FAQ — локальные массивы в компонентах.
- Для подключения реального API замените мок-массивы на запросы (например, `fetch` в серверных компонентов) или пропсы, прокинутые из `page.tsx`.

## Чек-лист приёмки
- Lighthouse (mobile): Performance, Accessibility, Best Practices, SEO ≥ 90.
- Полная адаптивность `sm` / `md` / `lg`.
- Проверка фокусов и клавиатурной навигации.
- Функциональность форм (валидация email, required-поля быстрой брони).
- Светлая и тёмная темы без визуальных артефактов.
