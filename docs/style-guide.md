# QueueCut Style Guide

## Типографика
- **H1** — 48–60 px, `font-semibold`, `tracking-tight`, используется в Hero.
- **H2** — 32–40 px, `font-semibold`, для заголовков секций.
- **H3** — 20–24 px, `font-semibold`, для карточек и подзаголовков.
- **Body** — 16 px (`text-base`), цвет `#6B7280` в светлой теме и `#D1D5DB` в тёмной.
- **Small** — 14 px (`text-sm`), для подписей и вспомогательных текстов.
- Межстрочный интервал: 1.4–1.6 в зависимости от блока (Tailwind `leading-relaxed` по умолчанию).
- Акцентные подписи используют uppercase, `tracking-widest`, цвет `#1f5e43` или нейтраль с прозрачностью.

## Отступы и сетка
- Основной контейнер: `max-w-7xl`, горизонтальные отступы `px-4 sm:px-6 lg:px-8`.
- Вертикальные интервалы секций: `py-20` (80 px) на десктопе, адаптивно сжимается на мобильных.
- Карточки: `p-6`, `rounded-2xl`, `shadow-sm`, при hover `hover:shadow-md`.
- Сетка карточек: `grid gap-6`, брейкпоинты `md:grid-cols-2`, `xl:grid-cols-4`.
- Формы и CTA: `space-y-4` между полями, `gap-4` для инпутов в одной строке.

## Радиусы и тени
- Радиусы: карточки `rounded-2xl`, кнопки `rounded-xl`, бейджи `rounded-full`.
- Тени: базовая `shadow-sm`, усиленная при hover, кастомная `shadow-card` для крупных блоков.
- Header использует `shadow-header` при прокрутке и `backdrop-blur`.

## Цветовые тона
- **Светлая тема:** фон `#ffffff`, текст основной `#111827`, нейтральный текст `#6B7280`, бордеры `#E5E7EB`.
- **Тёмная тема:** фон `#0b0b0d`, карточки `#16181d`, текст `#e5e7eb`, нейтраль `#9CA3AF`, бордеры `rgba(255,255,255,0.08)`.
- Акцент: `#1f5e43` для CTA, иконок, подчёркивания ссылок.
- Состояния: success `#16a34a`, warning `#f59e0b`, error `#ef4444`.
- Примеры: карточки FAQ используют `card-surface`, CTA — градиент `from-accent/10`, кнопки — `bg-accent` и `border-accent`.

## Примеры микрокопи
- **Карточка преимущества:** «Экономия времени — свободные слоты прямо сейчас, без звонков и ожиданий».
- **CTA:** «Подключайся и записывайся в один тап» + кнопка «Получить приглашение».
- **FAQ:** «Нужна ли предоплата? — Нет. Можно забронировать слот бесплатно и оплатить уже в салоне…».
- **Отзывы:** «Раньше приходилось звонить, теперь всё в пару кликов…».

## Доступность и взаимодействие
- Все интерактивные элементы имеют `focus-visible` стили и контрастный обводку.
- Анимации ограничены `transition duration-200` и `motion-safe` классы для плавности без перегрузки.
- Тон коммуникации: дружелюбный, уверенный, без жаргона, с акцентом на экономию времени.
